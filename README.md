# VideoGrab
Android video downloader powered by yt-dlp + ffmpeg (youtubedl-android). Paste or share a link, pick quality (MP4) or MP3, download with progress/speed/size, pause/resume/cancel, history + file manager.

## Build & install
1. Create a GitHub repo, upload this whole folder (keep the `.github` folder), push to `main`.
2. Open the **Actions** tab, wait for "Build APK" to finish (~5-8 min).
3. On your phone open the repo's **Releases** page, tap `VideoGrab.apk` under "VideoGrab (latest)".
4. Allow "Install unknown apps" for your browser when prompted, then install.

## Notes
- Private/friends-only Facebook videos, DRM streams (Netflix etc.) and login-gated content are not supported.
- If a site stops working, reopen the app on Wi-Fi: it auto-updates yt-dlp on launch.
